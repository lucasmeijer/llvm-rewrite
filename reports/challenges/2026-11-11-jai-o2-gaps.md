# The "remaining -O2 gaps" task hides a large analysis (DependenceAnalysis) and an LLVM nondeterminism

- **Date / implementation / unit:** 2026-11 (see file name) / jai / L1.early-cse, L1.sccp, L1.o2-gaps
- **What happened:** The task bundled six passes. EarlyCSE, SCCP/IPSCCP (+ PredicateInfo, FunctionSpecialization),
  MergeICmps and DFAJumpThreading were each a few hundred to ~1500 LLVM lines on top of existing infrastructure and
  went through. LoopInterchange looked like "one more pass" in the list, but it needs DependenceAnalysis (2922
  lines) and Delinearization (877), plus LoopCacheAnalysis (739) for the `cache` profitability rule, none of which
  exist in impl/jai. It did not fit after the other five. Separately, FunctionSpecialization iterates
  `SmallPtrSet<Function *, 8> OriginalFuncs`; above 8 elements that is pointer order, and on sqlite3 with
  `-force-specialization` LLVM's result really depends on it (a function is deleted or kept depending on which
  specialized function's call sites are updated first).
- **Time or effort lost:** reading LoopInterchange far enough to see the DA dependency (small); for the SmallPtrSet
  issue, ~30 minutes of narrowing down a silent difference on sqlite3 before seeing it is not reproducible from IR.
- **What would have helped:** listing the analyses a pass needs next to each roadmap pass (the roadmap unit for
  loop-interchange should depend on an `L1.analysis.dependence` unit with its own `print<da>` tests
  (tests/imported/llvm/Analysis/DependenceAnalysis). A knowledge note on "LLVM containers whose iteration is
  pointer order" (SmallPtrSet beyond its small size, DenseMap/DenseSet of pointers) with the rule to fail loudly
  where the order decides the output.
- **What you did instead:** imported the LoopInterchange tests and added roadmap unit L1.o2-gaps (MergeICmps,
  DFAJumpThreading, LoopInterchange); MergeICmps and DFAJumpThreading are complete, LoopInterchange is not
  started. For the SmallPtrSet order, impl/jai fails loudly exactly when a different order could change the
  result (knowledge/llvm/sccp.md).
