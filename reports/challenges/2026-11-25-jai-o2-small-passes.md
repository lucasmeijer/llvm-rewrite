# Generated intrinsic attribute table needs a test that declares every intrinsic a pass creates

- **Date / implementation / unit:** 2026-11-25 / jai / L1.scalar-misc (+ the small -O2 pipeline passes)
- **What happened:** ee-instrument creates `llvm.returnaddress` and rel-lookup-table-converter
  `llvm.load.relative`. impl/jai builds intrinsic declarations from gen_intrinsics.jai, which is generated by
  running LLVM over every test that *mentions* an intrinsic. When a pass creates an intrinsic no test declares, opt
  fails ("no entry in the generated attribute table") even though the pass is correct. I added
  tests/roundtrip/intrinsics/pass-created.ll just to declare them and regenerated the table.
- **Time or effort lost:** small (~15 min), but it will recur for every pass that creates a new intrinsic.
- **What would have helped:** a documented place for "intrinsics passes create" (now that file), or a generator
  that evaluates Intrinsics.td attributes directly.
- **What you did instead:** the roundtrip file; NOTES.md says to add more intrinsics there.

Also noted: `opt -print-pipeline-passes` output for `default<O2>` is not a faithful textual pipeline
(`extra-simple-loop-unswitch-passes` loses its inner pass), so "run the printed O2 pipeline with -passes=" is not a
complete substitute for `-O2` when the O2 unit starts.
