# Challenge reports

For the human who designs the loop that drives the agents. One file per report:
`<YYYY-MM-DD>-<lang or harness>-<slug>.md`, following [TEMPLATE.md](TEMPLATE.md). One file per report means
concurrent agents never conflict.

Write one whenever the *process* got in your way: unclear or contradictory instructions, a unit that was too big or
badly ordered, harness output that misled you, a missing tool, a flaky test, time spent going in circles, a decision
you had to guess at. Not for compiler bugs you simply fixed. Those go in `knowledge/` or `NOTES.md` if they're worth
remembering.
